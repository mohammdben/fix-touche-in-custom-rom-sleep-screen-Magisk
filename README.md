# Screen Lock Click Fix

A Magisk module designed to fix the unwanted clicking/touch issue that may occur when turning off or locking the screen.

## Features

* Fixes the clicking issue when turning off or locking the screen.
* Lightweight and simple.
* Designed to work without modifying the system partition.
* Can be removed at any time through Magisk.

## Compatibility

This module was specifically tested on:

* **Device:** Samsung Galaxy A02s (SM-A022F)
* **ROM:** LineageOS 19.1

It may also be compatible with other Android ROMs and devices, but compatibility outside the tested configuration has not been fully verified.

## Installation

1. Download the latest ZIP release of the module.
2. Open **Magisk**.
3. Go to **Modules**.
4. Select **Install from storage**.
5. Choose the module ZIP.
6. Reboot your device.

## Uninstallation

The module can be removed directly from the **Magisk Modules** section. Reboot your device after removing it.
